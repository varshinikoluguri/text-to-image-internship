Text-to-Image Generation Using Deep Learning

Intern: Koluguri Varshini

Project Overview

This project explores text-to-image generation using deep learning techniques. It covers pretrained generative models, Conditional Generative Adversarial Networks (CGANs), text preprocessing and embeddings, dataset analysis, attention mechanisms, and an integrated text-conditioned image-generation pipeline.

Objectives

- Explore pretrained text-to-image models and fine-tuning concepts.
- Generate basic shapes using a Conditional GAN.
- Process text prompts and represent them as numerical embeddings.
- Examine image datasets and their characteristics.
- Explore attention mechanisms in generative models.
- Connect text representations with image generation.

Tasks

1. Pretrained Model Fine-Tuning: Explore a pretrained text-to-image model and fine-tuning techniques.
2. Conditional GAN: Generate circles, squares, and triangles using class labels.
3. Text Preprocessing and Embeddings: Process text prompts and create numerical representations.
4. Dataset Analysis: Explore image dataset characteristics and relevant text descriptions.
5. Attention-Enhanced GAN: Explore attention mechanisms in generative modelling.
6. Integrated Pipeline: Connect text prompts, embeddings, and a generator for text-conditioned image generation.

Technologies

- Python
- Google Colab
- PyTorch
- Deep learning and GAN concepts
- Text preprocessing and embeddings

Results and Limitations

The latest Task 6 test produced basic shapes with the intended labels. The generated images remained blurry and noisy, so image quality requires further improvement. Results for each task should be reviewed alongside the notebook outputs.
